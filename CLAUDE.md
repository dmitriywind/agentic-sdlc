# CLAUDE.md

Guidelines for Claude Code CLI interacting with `agentic-sdlc`.

## Build & Test Commands
- **Build**: `npm run build`
- **Typecheck**: `npm run typecheck`
- **Test Suite**: `npm test`
- **Single Test**: `node --test test/process.test.mjs`

## CLI Tool Commands
- `npx agentic-sdlc init`
- `npx agentic-sdlc validate`
- `npx agentic-sdlc supervise --once --read-only`
